# Claude Code on Amazon Bedrock

A hands-on workshop for supercharging team development with Claude Code on Amazon Bedrock. This full-day session covers setup, team standards, always-on agents, cost controls, and the broader Claude ecosystem.

## Agenda

| Time | Duration | Session |
|------|----------|---------|
| 8:00 – 8:15 | 15 min | Introduction & Getting Started |
| 8:15 – 9:15 | 60 min | Lab 1: Setup Claude Code for teams |
| 9:15 – 10:00 | 45 min | Lab 2: Establish team standards and workflows |
| 10:00 – 10:45 | 45 min | Lab 3: Level up your team with always-on agents, plugins, and search |
| 10:45 – 11:30 | 45 min | Lab 4: Scale confidently with visibility, cost controls, and secure practices |
| 11:30 – 12:00 | 30 min | Lab 5: Beyond Claude Code, Summary & Closing |

## Session Details

### Introduction & Getting Started (15 min)
- Supercharge your team development with Claude Code on Bedrock
- Setup your workshop & IDE
- Setup your AWS environment in terminal

### Lab 1: Setup Claude Code for Teams (60 min)
- Configure environment
- *(Optional)* Plan capacity by understanding Bedrock service quotas
- *(Optional)* Monitor basic costs
- *(Optional)* Select identity and access pattern
- *(Optional)* Install the IDE extension

### Lab 2: Establish Team Standards and Workflows (45 min)
- Establish team standards with CLAUDE.md and custom commands
- From vibe coding to spec-driven development: The EPCC workflow
- Scale workflows with Agent Skills and context engineering
- Manage large projects with tasks, checkpoints, and autonomous work features
- *(Optional)* Explore session productivity tips
- *(Optional)* Use git and parallel workflows
- *(Optional)* Extend Claude Code with integrations

### Lab 3: Level Up Your Team with Always-On Agents, Plugins, and Search (45 min)
- Run always-on agents
- Distribute workflows to your team as plugins
- Add web search
- Explore patterns and plugins: Security review, Smart documentation, Quality gates

### Lab 4: Scale Confidently with Visibility, Cost Controls, and Secure Practices (45 min)
- Connect through the Claude Apps Gateway
- Control spend with the gateway
- Deliver managed settings through the gateway
- Production patterns for the Claude Apps Gateway
- Understand coding agent observability
- Inspect the gateway telemetry pipeline
- Verify metrics reach CloudWatch
- Explore usage in Coding Agent Insights
- *(Optional)* Govern and establish secure practices

### Lab 5: Beyond Claude Code, Summary & Closing (30 min)
- Claude Agent SDK on Amazon Bedrock AgentCore
- Claude Desktop & Claude API
- Continue learning with Anthropic on AWS
- One ecosystem, many surfaces
- Summary, Q&A, and closing
